The upstream package is a PyTorch/Hugging Face implementation for causal transformer language models. Its declared dependencies include Torch, Transformers, Accelerate, NumPy, and Hugging Face Hub. It is not a drop-in dependency for the NumPy-like offline WHestBench sandbox.

## Mechanism actually implemented

For transformer residual state `h_l`, JSpace estimates the corpus- and position-averaged downstream Jacobian

`J_l = E[d h_final / d h_l]`.

It uses Rademacher Hutchinson probes and vector-Jacobian products. If `g = J_l^T v`, then

`E_v[v g^T] = E_v[v v^T] J_l = J_l`.

The source performs one forward pass and, for each probe, differentiates the same scalar target with respect to the saved states of all requested layers. Thus one backward traversal produces VJPs for every layer; it does not repeat a full forward/backward pass per layer.

JSpace then projects hidden states with `J_l h_l` and uses sparse nonnegative matching pursuit against a corpus dictionary. It stops at 95% squared-norm coverage or 30 atoms. Its workspace detector combines four relative signals: pursuit capacity, next-token accuracy, adjacent-position autocorrelation, and an entropy valley.

The primary paper defines J-space as a sparse nonnegative cone generated by token-indexed J-lens vectors. The nonnegativity therefore has a semantic/token-cone justification in the LLM setting; it is not a generic theorem about Jacobian features.

## Exact transfer to bias-free deep ReLU estimation

The legal transferable unit is the estimator mathematics, not the Hugging Face package:

1. For a spherical input `u` and layer state `h_l(u)`, compute the downstream Jacobian `D_l(u) = d f(u)/d h_l` using the known weights and ReLU gate masks.
2. Fuse the reverse recurrence so the same output probe yields response vectors at all layers.
3. Compare two cleanroom summaries:
   - signed mean lens: `M_l = E_u[D_l(u)]`;
   - energy lens: `G_l = E_u[D_l(u)^T D_l(u)]`.
4. Estimate `G_l` without forming every dense Jacobian: for Rademacher output probes `v`, `E[(D_l^T v)(D_l^T v)^T] = D_l^T D_l`.
5. Use layerwise spectra only to define an invariant, frozen response dictionary or a distillation/control-variate family. Any pilot fit and teacher pass must be billed, cross-fitted, and permutation/gauge equivariant.

## Crucial mismatch and planned falsification

WHestBench has no vocabulary, token semantics, positional axis, residual stream, or trained concept cone. A fixed iid-Gaussian ReLU MLP also has strong neuron permutation/sign-gauge symmetries and input-dependent gate patterns. Therefore:

- nonnegative pursuit is only an ablation; signed pursuit is the symmetry-compatible comparator;
- token accuracy becomes downstream-observable fidelity;
- positional autocorrelation becomes adjacent-depth subspace/response autocorrelation;
- token entropy becomes a normalized spectral entropy or participation-ratio signal;
- the paper's averaged signed Jacobian can cancel under gate tumbling, so `E[D^T D]` is the primary alternative;
- layer selection may be learned only on disjoint cleanroom networks and then frozen. It may not use official truth or private scorer feedback.

## Competition deployment gate

No JSpace code or Torch dependency enters a submission. A candidate advances only if a NumPy cleanroom implementation:

- reproduces exact dense Jacobians at small width;
- passes JVP/VJP adjoint, Euler homogeneity, permutation, and gauge tests;
- shows stable held-out response compression across fresh synthetic networks;
- produces a variance reduction that survives the full billed-cost ledger;
- remains complementary to the randomized-radial chi-q3 parent estimator.

Until those gates pass, JSpace is a source of candidate operators, not evidence that a winning estimator exists.
