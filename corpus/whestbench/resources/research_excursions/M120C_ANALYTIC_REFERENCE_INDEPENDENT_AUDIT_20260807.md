## What passes

### Analytic derivation

The local kernels have the correct central-covariance convention. With
p_i = Phi(alpha_i), m_i = sigma_i phi(alpha_i) + mu_i p_i, and
r_i = phi(alpha_i)/(2 sigma_i), the implemented diagonal identities are

    price[i,i] = p_i
    H_mu[i,i] = 2 m_i (1 - p_i)
    H_var[i,i] = p_i - 2 m_i r_i.

For i != j, Plackett gives price[i,j] = L = Phi2(alpha_i,alpha_j;rho). The
code uses

    d_i = phi(alpha_i) Phi((alpha_j-rho alpha_i)/sqrt(1-rho^2)) / sigma_i
    E[X_j 1_i 1_j] = mu_j L + C_ji d_i + C_jj d_j
    H_mu[i,j] = E[X_j 1_i 1_j] - p_i m_j
    H_var[i,j] = 1/2 f_Xi(0) E[ReLU(X_j)|X_i=0] - r_i m_j.

Those are the correct mean and central-covariance derivatives. The conditional
ReLU moment, bivariate raw second moment, symmetric off-diagonal contraction,
and diagonal overwrite in analytic_dense_pullback also follow from those
identities. No finite-difference calculation enters the binding module.

### Plackett sign, state acceptance, and prohibited mechanisms

Phi2(a,b;rho) = Phi(a)Phi(b) + integral(0,rho) phi2(a,b;t) dt is used with the
signed integration interval, so negative correlation is subtracted rather than
accidentally reflected. The source has genuine 32/64-point Gauss--Legendre
paired estimates; no ten-point rule is present.

State validation rejects non-finite values, non-exactly-symmetric covariance,
variance <= 1e-10, and eigenvalue <= 1e-10. It rejects
abs(rho) >= 1 - 1e-10 before the singular density. Conditional variance is a
Schur complement of an already accepted SPD covariance and is checked again by
the conditional ReLU helper. FLOOR is an input rejection threshold, not a
numerical floor. I found no clipping, denominator replacement, PCG64,
default_rng, old fullcov, or finite-difference machinery in the module.

## Required repair: aggregate paired-order convergence is not fail-closed

quadrant_probability documents that it bisects until the **sum** of local
paired-order disagreements is at most QUADRATURE_TOLERANCE. Its controller does
not guarantee that statement:

    if local <= QUADRATURE_TOLERANCE / max(1, len(pending) + 1):
        accepted += fine
        disagreement += local

The denominator is based only on the current pending count. An accepted early
interval can consume part of the budget; later accepted intervals are then
allowed their own dynamically enlarged budgets. There is no final
disagreement > tolerance rejection.

I verified the control-flow defect without changing a source file: while
temporarily replacing only the in-memory interval evaluator, the root interval
had paired discrepancy 2T and was split; its two children had discrepancies
0.49T and 0.99T, each within the controller's current local allowance. The
unmodified function returned normally with disagreement 1.48e-13 for
T = 1e-13, one subdivision, and a range-valid result 0.25000000000014799. The
original evaluator was restored immediately. This is a deterministic
counterexample to the acceptance policy, not an assertion that ordinary
Gaussian integrands currently hit the condition.

analytic_local_kernels happens to reject a completed pair whose reported
aggregate indicator exceeds T, protecting the pullback path. However,
quadrant_probability itself returns the violating value, and
analytic_relu_gaussian_moments consumes quadrant values without checking the
reported disagreement. Therefore the module as a whole does not meet the
claimed fail-closed reference contract.

### Exact acceptance criterion for re-audit

1. Replace the local, pending-count allocation with a global adaptive loop
   that recomputes/splits intervals until the **sum** of accepted paired-order
   indicators is <= QUADRATURE_TOLERANCE, or reaches the 4096 split cap and
   raises AnalyticReferenceFailClosed.
2. At minimum, enforce a post-convergence aggregate check in
   quadrant_probability that raises rather than returns when the sum exceeds
   the tolerance. A global refinement loop is preferred because it preserves
   the documented bisect-until behavior rather than unnecessarily rejecting an
   otherwise convergent integral.
3. Add a regression test for the aggregate-budget controller (a mocked
   interval evaluator is suitable) and ensure all forward moment callers
   inherit the same rejection. Re-run the source suite and a fresh Philox
   directional check after the repair.

All other audited R3 analytic and rejection properties pass. This single
adaptive-convergence issue is the only blocker found in the scoped audit.
