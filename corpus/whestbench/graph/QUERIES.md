# Predeclared Graphify queries

The local semantic graph must answer these before any new estimator is built.

1. What is the shortest evidence-supported path from a cheap analytic method
   to a score competitive with the frozen sampler?
2. Which pair of rejected methods fail for complementary rather than identical
   reasons, and what concrete hybrid removes both failures?
3. Which surviving candidate attacks the connected four-point vertex without
   O(n^4) storage or O(n^5) transport?
4. What observable can predict the sign-changing per-network oracle hybrid
   coefficient without using truth at inference?
5. Which biological, memristive, retinal, fractal, tau, quantum, or
   renormalization analogy survives translation into a legal operation and a
   falsifiable gate?
6. What is the cheapest premise experiment that can kill equivariant learned
   residual closure?
7. Which proposed hybrids are already forbidden by the mediant dilution law,
   approximate-mean theorem, frame annihilation, or scorer cost cliff?
8. What information is shared by the full-covariance residual, k3/k4 oracle
   gap, and finite-width directional-variance inflation?
9. Which graph bridge has high novelty but weak evidence, and which has lower
   novelty but the best current empirical support?
10. Given that random 32,256 was promoted while H1, H3, finite-memory k3, and
    the standalone adjoint branch were killed, which surviving observable can
    repair downstream mean/covariance reclosure without recreating O(Ln^4)?
