## Exact or unexpectedly useful edges that survive hostile review

1. **M86 signed spherical coarea:** a homogeneous PWL ReLU output equals its
   signed output-fan jump measure divided by `d-1`; raw cascaded gate labels
   must be collapsed to one output-facet jump.
2. **M87 shared-middle contraction:** for `M_b=Q diag(u_b) Q`, an exact
   four-cycle uses shared middles rather than all `r^2` pair products.  This
   lowers a contraction bill but does not create a bridge/source factor.
3. **M90/M93 bridge-to-cumulant separation:**
   `E=a1 R_off+G` has a broad full-rank linear bulk, but the pure all-linear
   connected k3/k4 contribution is exactly zero.  The retained mixed
   H/linear terms are nonzero, so “delete Wishart everywhere” is false.
4. **M95 local d=2 Palm law:** a uniform start selects an output-fan event
   with `q=preceding-sector-gap/(2pi)`, recoverable by local predecessor
   discovery; its HT estimator is exact.  Its variance failure is a property
   of this proposal, not a refutation of coarea.
5. **M98 coordinate/control repair:** source-to-current transport can be
   permutation equivariant; message-only row/column intervention leaves the
   Gaussian anchor bitwise fixed; the node-only mode truly zeroes message
   columns.  The resulting carrier still fails accuracy and mechanism gates.

## Recommended H-numbered corpus snippets

### H61: source formation is distinct from transport and compression

`M85/M87/M90/M91` show that pair bridges, exact shared-middle contractions,
rank compression, and stochastic trace sketches are downstream consumers.
They cannot manufacture the required fixed-network 3-/4-unique source.  Any
child must first expose a billed source observable and separately test every
index-multiplicity stratum.

### H62: connected first-chaos cancellation creates a narrow analytic opening

For centered standardized ReLU `g=c1 Z+H`, all-linear Gaussian connected k3
and k4 vanish exactly.  The remaining mixed H/linear terms are nonzero.  This
removes a raw moment loop, not the whole source, and licenses only a new
mixed-vertex construction with parity and resource gates.

### H63: boundary exactness and boundary efficiency are separate nodes

M86/M95 prove signed facet calculus and an exact local d=2 Palm inclusion
law.  M89/M95 kill complete-circle and uniform-first-crossing efficiency.
Future boundary work must alter the inclusion/variance mechanism, prove the
output-facet law, and compare variance times complete charged work.

### H64: transport attention is a carrier, not an observable

M98 validates permutation-safe message transport and control isolation but
fails its terminal and causal gates.  A successor cannot tune this cell.  It
must inject a newly derived weights-computable state and demonstrate that its
edge-specific ablation removes the resulting gain.

### H65: causal learned comparisons require capacity and optimizer parity

The raw control must match input dimension/parameter count and begin from the
same state; full and node-only arms must use identical optimizer-order
randomness unless difference is preregistered.  Retain per-network reference
SE, sample level, model artifact only after all gates, and target resource
traces.

### H66: the input layer is an identity-chaos boundary

Rectified Hermite responses start only after the first affine/ReLU gate.  At
the input, the exact response is `(gamma1,gamma2,gamma3,gamma4)=(1,0,0,0)`.
This boundary is a coordinate/semantics invariant, not a parameter choice.
