## God node: M125b coalesced inhomogeneous tangent

For a frozen Gaussian background, every first-Born source sees the same
linearized downstream Jacobian.  Therefore explicit per-source propagation

```text
sum_k J_(L<-k) s_k
```

is exactly the terminal state of one inhomogeneous recurrence

```text
x_(l+1) = J_(l+1) x_l + s_(l+1).
```

This is an algebraic fold, not approximate batching.  It reduces 465 tangent
stages to 30 while preserving the final signed correction.  It discards only
per-source diagnostics.  Promotion requires dense small-width equality for all
outputs, source-index/terminal ownership checks, float64-aware FlopScope
accounting, and positive-gauge/permutation covariance.

## Branch M126: direct repeated-output source contractions

M124 spends nearly all cost constructing a global rank-four source projector,
but the Edgeworth response needs only repeated-output slices
`aaa`, `aab`, `aaaa`, `aaab`, and `aabb`.  Tree stars, k3, aaab, and adjacent
k4 paths admit exact all-output `O(n^3)` matrix identities.  The hard node is
the alternating `ABAB/iijj` path, a Khatri--Rao quadratic form.

A mechanism-changing child can split its bridge as `Q=I+E`: evaluate the
identity contribution exactly and estimate only the zero-diagonal residual.
For an outcome-independent Rademacher/Hadamard probe `z`, set

```text
M_z = A^T diag(g*z) W,
M_Ez = A^T diag(g*(E z)) W.
```

Entrywise products `M_z[a,b] M_Ez[a,b]` and
`M_z[a,b] M_Ez[b,a]` estimate all hard self/cross tables at once.  Two dense
products per probe service all hard orbits.  Promotion requires an exact
expectation proof, collision ownership, orthogonal-probe variance analysis,
small-width dense parity, and a frozen probe count selected without outcomes.

### M129 differentiated-source update

The missing Frechet source derivative now closes algebraically, including the
`[2,1,1]` collision ownership.  For packed hollow coefficients `A_i;jk` and a
Rademacher probe `z`, the same probe can differentiate all repeated-output
tables pathwise.  Writing `u=W^T z`,
`t_i=2 sum_{j<k} A_i;jk z_j z_k`, `M=W^T diag(t) W`, and `d=diag(M)`, the
required fourth-order tables reduce to

```text
K_aaaa = 3 d_a u_a^2
K_aaab = (3/2) (M_ab u_a^2 + d_a u_a u_b)
K_aabb = .5 (d_a u_b^2 + d_b u_a^2) + 2 M_ab u_a u_b.
```

Using the same `z` for `A` and its tangent gives an unbiased pathwise source
derivative; the current layer still needs a fresh probe conditional on prior
stochastic tangents.  This eliminates the apparent `O(n^4)` transport.
