# M221 disposition: KILL

M221 does **not** promote.  It preserves M216's exact strict-distinct
antithetic atom and establishes a useful compiled execution baseline, but both
independently frozen promotion gates fail.  Per the predeclaration, no variance
experiment was created or run.

## Numerical gate

The specialized recurrence itself is accurate inside its chart:

- all 2,730 ungauged census events stay in chart;
- the maximum deviation from the scalar M216 parent is
  `2.0261570199409107e-15`;
- all 17 independent 80/100-dps oracle probes pass, with maximum midpoint error
  `1.7416623698807143e-15`;
- the returned radius ratio is `1e-8`, below the frozen `2e-7` requirement; and
- the inherited M216 worst event passes.

The full numerical gate nevertheless fails its response-free invariance test.
Positive gauge transforms move 81 of 90 probes outside the physical
`[0.8, 1.2]` conditional-sigma chart (`0.7501602937357109` to
`1.6302056710878285`).  The common in-chart values remain gauge-consistent to
`1.8659063985293372e-16` scaled error, so this falsifies the chart/enclosure,
not the strict-distinct identity.  Singleton permutation remains clean.

## Static and native execution gate

The pre-target affine ledger is exact on every fresh-process run:

- 3,968 events;
- `21,760,512` billed FLOPs (`5,484` per event);
- `11,911,936` charged allocation bytes;
- 18 staged columns, 40 workspace buffers, 58 charged `empty` calls, and 23
  charged `copyto` calls; and
- no unlisted user temporaries.

The compiled output matches the independent NumPy recurrence to at most
`5.30825383648903e-16`, only `5.2300677309336504e-8` of its returned enclosure.
All hostile components are far under M214's `6,824,272,176` ceiling: the worst
is `727,810,387.5890876`.

But the execution gate fails twice:

1. Every seed has exactly 68 fallbacks, all and only because
   `abs(pair_rho) > 0.04`; the observed maximum is `0.07885550264503906`.
2. Raw wall is `18.1205..21.5691 ms`, only `74.80..89.04x` faster than M216.
   The fastest run is `1.12313x` the frozen `16.1339 ms` limit, so none exceeds
   100x.
