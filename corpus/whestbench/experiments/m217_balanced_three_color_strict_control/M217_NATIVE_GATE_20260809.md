# M217 native-gate supplement -- frozen before sidecar implementation

This supplement resolves the target dimensions left implicit in the parent
predeclaration. It was written after the small-width algebra passed and before
any FlopScope sidecar existed or target trace ran. It does not change the
parent thresholds.

```text
FlopScope       0.10.0
dtype           float64
source layers   31
label/output n  256
class rows      86,85,85, padded only where a supported call requires it
Gram schedule   depth-3 output-column recursion, class and layer batch axes
matmul calls    exactly 4 for all class-local self-Grams
```

The same live operand object must occupy both self-Gram positions inside each
recursive diagonal block, and off-diagonal output blocks must be computed once
then explicitly mirrored. A dense three-Gram worksheet is not a lower bound:
the frozen experiment is specifically the symmetry-recursive circuit already
validated by M209--M212, now with the color class as another batch axis.

Color packets must be generated once, bound to a layer epoch, and jointly
permuted with labels. Input gathers, zero padding, reductions, output assembly,
mirrors, copies, reshape materializations, allocation, and wall time are all
charged. No raw NumPy arithmetic or hidden participant-created packing is
allowed in the target path.

The native gates remain exactly the parent values: arithmetic at most
`1.600000000B`, hostile `bill+5e11*wall` at most `2.250000000B` on every
frozen seed, and peak allocation at most 512 MiB. A pass is only a resource
component pass; source variance remains closed.
