## 4. Formulas, strata, and derivative definitions

Domain: finite binary64 `(a, b)`, `|rho| <= 1 - 2^-52`.  Everything else
refuses (`NONFINITE_INPUT` / `NON_SPD_OR_RANK_ONE_CHART`); rank-one,
zero-variance, deterministic, and non-PSD inputs belong to M177's other
strata and are never silently evaluated as SPD.  Two boundary charts keep
the full finite domain sound (both adversarially motivated, disclosed as
Errata 6-7): means with `0 < |mean| <= 1e-290` dispatch to the exact
zero-mean limit (V6), and the reduction path's `q -> +-inf`
overflow/underflow channel dispatches to the exact `T(h, +-inf) =
+-(1 - Phi(|h|))/2` limit via saturated `Phi` and a vanishing inner T,
guarded so `inf * 0` can never form.

With `s^2 = (1-rho)(1+rho)` (anti-cancellation form; `1-rho` exact by
Sterbenz for `rho >= 1/2`):

```text
Phi2(a,b;rho) = (1/2)Phi(a) + (1/2)Phi(b) - T(a, q_a) - T(b, q_b) - delta
q_a = (b - rho a)/(a s),  q_b = (a - rho b)/(b s)
delta = 0 if ab > 0 or (ab = 0 and a + b >= 0); else 1/2
T(h, q) = (1/2pi) Int_0^q exp(-h^2(1+x^2)/2)/(1+x^2) dx
```

Zero-mean strata use the exact limits `T(0,q) = arctan(q)/(2 pi)`,
`T(h, +-inf) = +-1/4` sign-carried, and
`Phi2(0,0;rho) = 1/4 + arcsin(rho)/(2 pi)` with `arcsin(rho) =
arctan(rho/s)`.

Second-argument reduction to `q in [0,1]` (proved by the polar/sector
decomposition of the standard bivariate normal; numerically cross-validated
by the reduction-free R1 reference on every grid point):

```text
T(h, q) = (1/2)(Phi(h) + Phi(qh)) - Phi(h)Phi(qh) - T(qh, 1/q),  h,q > 0
T(h,-q) = -T(h,q);  T(-h,q) = T(h,q)
```

`qh` is computed stably as `(b - rho a)/s`, never by forming an overflowing
`q` first; the `|q| <= 1` test compares `|b - rho a|` against `|a| s`.

Reduced-domain quadrature, `c = h^2 q^2/2`:

```text
T(h,q) = (q e^{-h^2/2} / 2pi) * I(h,q),
I(h,q) = Int_0^1 e^{-c u^2} / (1 + q^2 u^2) du   (20-node GL, fixed)
```

Deep-tail chart `c > 18`: certified bracket `[0, q e^{-h^2/2}/(2 pi)]`,
midpoint returned, half-width `<= exp(-18)/(4 pi) = 1.212e-9`.

Phi/phi are built from charged elementary operations only (the installed
billed normal-CDF surface has no error contract — the exact M177 finding —
and is banned here):

```text
Phi(h) = 1/2 + (1/2) erf(h/sqrt 2)
erf chart A, |x| <= 3.5: fixed 52-term Taylor (Horner in x^2)
erf chart B, 3.5 < x < 27: two-sided 4-term asymptotic (Mills) enclosure
erf chart C, |x| >= 27: saturation, width < 1e-300
phi(h) = e^{-h^2/2}/sqrt(2 pi)
```

Derivatives (obtained by differentiating the defining integral; the
quadratic form uses the exact positive rewrite
`a^2 - 2 rho a b + b^2 = (a - rho b)^2 + s^2 b^2`, so no cancellation):

```text
dV/da   = phi(a) Phi((b - rho a)/s)
dV/db   = phi(b) Phi((a - rho b)/s)
dV/drho = exp(-(t_b^2 + b^2)/2) / (2 pi s),   t_b = (a - rho b)/s
```

Inputs are canonically ordered (`a <= b`, derivative outputs swapped back),
making swap symmetry bitwise by construction.

**(V1) GL20 truncation, self-contained.**  On the closed rho=2 Bernstein
ellipse of `[0,1]` (semi-axes 0.625/0.375 about center 1/2) the integrand

(contour-shift argument, two lines: expand f(cos t) in its Laurent series

## 6. Certified remainder proof (derivatives) and rounding model

Predeclared op model: IEEE-754 binary64 correct rounding for
`+,-,*,/,sqrt` (`u = 2^-53`); numpy/libm `exp` and `arctan` faithful
within 2 ulp — a declared assumption (protocol f), validated on the whole
hostile grid against 50-digit references; any violation is a kill-gate-2
event.

**(D1) s and t conditioning.**  `s^2 = (1-rho)(1+rho)` carries `<= 2.5u`
relative error including the square root (Sterbenz exactness of `1-rho`
for `rho >= 1/2`; plain `u` bounds below).  For `t = (num)/s` with
`num = b - rho a`: the product contributes `u|rho a|`, the correctly
rounded subtraction a further `u|num|`, the division `u|t|`, and s's
`2.5u`, so `|Delta t| <= u(|rho a|/s + 4.5|t|)`.  (An adversarial 60-digit
sweep found the earlier draft coefficient 3.5 violated at 3 of 400,000
points, worst ratio 1.0096 — Erratum 8; the corrected 4.5 chain is what
the downstream bounds use.)

**(D2) dV/da (and by symmetry dV/db).**  `d_a = phi(a) Phi(t_a)`.  The
Phi-perturbation sensitivity is `phi` evaluated on the perturbation
interval, i.e. `~phi(t_a)`, NOT a global `phi_max` (a global 0.4 would
make the `|t_a|`-proportional term of D1 unbounded).  Splitting D1's
`|Delta t_a|`:

```text
err <= phi(a)*ERR_PHI                                  <= 0.4e-9
     + phi(a)*phi(t_a)*u*|rho a|/s                     <= 5.2e-10
     + phi(a)*phi(t_a)*4.5u*|t_a|                      <  1e-16
     + |d_a|*5e-13
```

The second line uses `phi(a)|a| <= phi(1) = 0.2420` and `s >= 2.1073e-8`;
the third uses `|t|phi(t) <= phi(1)` so
`phi(0)*phi(1)*4.5u = 4.8e-17 < 1e-16`.  Total
`< 1e-9 + 5e-13|d_a| <= 5e-9 + 1e-8|d_a| = w_da`.  Proven.

**(D3) dV/drho.**  `d_rho = e^{-E}/(2 pi s)` with
`E = (t_b^2 + b^2)/2` (exact positive-form identity).  With D1's corrected
chain the computed E carries `|Delta E| <= u E (1/s + 11) + 2 u E`
(AM-GM: `|t_b||b| <= E`), so the relative error of `d_rho` is
`<= u E (1/s + 13) + 3 ulp`.  The
absolute-plus-relative contract `err <= 5e-9 + 1.2e-7 |D|` holds because,
writing `S = 1/s <= 4.746e7`, the requirement
`u E S <= 1.2e-7 + (5e-9)(2 pi / S) e^{E}` is monotone-worst at
`S = S_max`, where it reads `5.27e-9 E <= 1.2e-7 + 6.6e-16 e^E`; the left
side minus the exponential term is maximized near `E = 15.9` at `7.9e-8 <
1.2e-7`.  For `E` large the result underflows toward zero and the 5e-9
absolute floor dominates by hundreds of orders of magnitude.  Proven.

**(D4) Enclosure formulas returned.**  `w_da = w_db = 5e-9 + 1e-8|D|`,
`w_drho = 5e-9 + 1.2e-7|D|`, both stated at the proven level (D2)/(D3),
both within the locked derivative tolerance `2e-7 + 2e-7|D|`.
