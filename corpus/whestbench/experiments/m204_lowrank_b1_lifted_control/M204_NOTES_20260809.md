# M204 derivation and scope notes

M204 is not a generic low-rank approximation to an M179 covariance.  The
rank-one factor preserves the incoming diagonal exactly and supplies a
deterministic non-Gaussian conditional-moment functional:

```text
V_canonical = u u^T + diag(d),
u_i = sqrt(V_ii) / sqrt(n_active),
d_i = V_ii - u_i^2.
```

The two active Rademacher nodes have the fourth moment

```text
E[(u_i z)^2 (u_j z) (u_k z)] = u_i^2 u_j u_k.
```

For distinct labels this equals the first covariance pairing.  Subtracting
M151's covariance star removes that pairing and the two split pairings,
leaving exactly `-2 u_i^2 u_j u_k`.  This cancellation is why the lifted
source needs one terminal contraction rather than M155's generic masked
Khatri--Rao action.

The complete-domain lift is inherited from M156: collisions have target zero,
but the exact residual carries `-c` there.  This avoids changing any physical
collision owner in expectation.  It also means collision tails are an
unmeasured risk; M204 deliberately does not run a source-variance test until
the separate strict native-cost premise is proved.

The factor is based on diagonal scale rather than a latent eigensystem.  That
avoids arbitrary right-factor rotations and label-dependent tie breaking.  It
does not claim that the factor is a faithful fourth-order state of the network;
unbiasedness follows from the residual add/subtract identity, while variance
remains an unopened premise.

M156 supplies the domain-lift law but not this state/compiler.  M163 is a
different exterior covariance control and is not composed.  M170's generic
oriented two-channel lower bound does not apply to this one-channel rank-one
identity, but it remains a warning that a block call cannot be used as free
arithmetic credit.  M199 likewise forbids treating the existing booked source
emission as shared until an integrated native trace proves it.
