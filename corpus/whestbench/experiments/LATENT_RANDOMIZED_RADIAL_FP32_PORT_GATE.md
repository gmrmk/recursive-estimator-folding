# Predeclared FP32 FlopScope production-port rung

Written before any port parity, cost, runtime, or memory metric.

## Objective and boundary

Port the screened Haar + positive two-node chi-radial, q=3 full-covariance closure to FlopScope 0.10.0 / WHestBench 0.14.0 in FP32. This rung uses synthetic iid-He weights only. It must not load WHest data, targets, scorer code, public rows, holdouts, locked rows, or any API.

The estimator is a deliberately biased assumed-density closure. Its parent screened survivor source hash is `150657841fb72b3150e32fe465fb4c24d12c4d11e90df2ce9f1dc22b306215cf`; its n=128 result hash is `0669df13335c22341f1e418e65f35245c4c3b05f68b8c2a55e622d77fdc311fb`.

## Frozen implementation choices

- All estimator state, random frames, spectral operations, moments, and predictions are FP32.
- The rotation seed is exactly `int(mlp.seed)` for each synthetic network. There is no seed bank, selection, hashing, comparison, retry, or best-pick.
- One RNG is initialized in `predict`; one `(n,n)` Gaussian matrix and one QR are billed per layer. No MLP-dependent work is performed in `setup`.
- The same Haar frame is shared across all components in a layer.
- The child order is component, radial node, coordinate, sign, output coordinate. Steady child count is `4*q*n`.
- Compression is a vectorized, noniterative three-bin cumulative-overlap allocation. The overlap tensor already contains probability mass and is used directly in bin moments. This corrects the prose pseudocode in `latent_randomized_radial_n128/PRODUCTION_PORT_SPEC.md`, which accidentally multiplied overlap mass by sorted probability a second time.
- Degenerate compressor directions or tied score order produce three equal-weight copies of the global moment match, retaining the fixed q=3 state shape.
- Covariances are tagged symmetric immediately after construction. Negative eigenvalues in square-root formation are clipped to zero.

## Gates

The port survives only if all conditions hold:

1. Every named internal stage agrees with the independent NumPy FP32 oracle at `rtol <= 5e-5`, `atol <= 5e-6`; integer orders agree exactly.
2. Repeated identical predictions are bitwise deterministic; the recorded rotation seed equals the network seed.
3. Outputs have shape `(L,n)`, are finite and nonnegative, and all four parity cases complete with zero failures.
4. At every layer the child shape is `(4*q*n,n)`, allocation is `(3,4*q*n)`, output state is q=3, bin masses are positive, and the noniterative reducer has no zero-progress path.
5. Final covariance symmetry/PSD tolerance passes: `lambda_min >= -2e-5 * max(trace(cov)/n, float32_tiny)`.
6. Target billed FLOPs are strictly below 76B (engineering safety) and 80B (hard arithmetic gate).
7. Effective compute is reported as `billed + 100B * residual_wall_seconds`. The conservative combined tail is the maximum of effective compute and the preregistered 70,590,136,320-operation bound. It must be below 76B to survive this rung.
8. Target external peak working set is strictly below 2GB and wall time strictly below 600 seconds.
9. Required FlopScope call counts are exact: 32 random normal draws, 32 QR calls, 64 eigendecompositions, 64 moment `einsum` calls, 32 sorts, and 32 cumulative sums.
10. Source/import audit finds no official-data or scorer access.

If a frozen implementation fails, preserve its passing stages and localize the failed gate. Code may be corrected only by changing the failed mechanism, then must receive a new freeze manifest before new metrics.
