# M198-G1 predeclaration: issuer-backed source and carrier receipts

Status: `PREDECLARED_NOT_EXECUTED`. G0 repaired ordinary aliasing and label
order, but the hostile rerun showed that self-consistent public records could
still be minted and that a free-form `LabelledTangent` could enter the carrier.
G1 changes only this trust boundary. It opens no variance, efficacy, native
cost, official data, scorer, leaderboard, or submission work.

## One changed mechanism

Split mathematical references from production receipts and verify every
production object against its upstream issuer:

1. reference contexts/sources may exercise the delay-one formula, but their
   outputs are unlabelled `TangentState` values and can never enter M125b;
2. production contexts are issued only while wrapping the exact M179 archive;
3. production sources are issued only by recomputing the M172 selective K22
   owner transfer from its actual generated weight, distinct table, physical
   owners, and covariance, including physical/control/residual and retained
   K4/K31 source contributions;
4. a production `LabelledTangent` contains its source and context plus a
   conversion receipt; carrier entry recomputes integrity and the delay-one
   result, rejecting arbitrary states or hexadecimal identifiers;
5. all integrity checks recompute canonical digests at every public boundary,
   catching `object.__setattr__` tampering despite Python frozen dataclasses.

## Frozen gates

- Same-label self-issued reference provenance is rejected by the production
  converter.
- An unrelated but internally consistent coefficient witness cannot authorize
  arbitrary emitted slots.
- Legacy K22 retention, collision re-zeroing, changed retained K4/K31 source,
  and source/witness substitution each fail.
- A manually constructed tangent, stale conversion receipt, tampered source,
  tampered context, or tampered tangent state fails before M125 arithmetic.
- Valid M172-issued sources on generated widths 2..7 pass old/new source
  conservation within `5e-10`, exact residual-table ownership, and the M198
  delay-one conversion.
- Valid labelled explicit and inhomogeneous carrier results agree within
  `2e-12`; reorder, duplicate, suffix swap, and terminal reinjection continue
  to fail.
- The independent oracle threshold tightens from `2e-6` to `2e-10`; fixture
  metadata records that Richardson produces an `O(h^8)` extrapolate and that
  the stored fine difference is a correction proxy, not a residual bound.

## Kill and scope rules

Any failed gate leaves M198 at `REPAIR`. Passing promotes only a response-free
generated algebra/interface component. The M172 source quantities used by the
issuer are still not a target-width affordable provider; integrated native
FlopScope cost, bounded liveness, source variance, whole-estimator MSE, and
private generalization all remain separate unopened gates.
