## 3. The decisive arithmetic

### 3.1 ρ_c is exactly zero

`_varying_dummy_event` has `C = [[1, 0.30, -0.25], [0.30, 1, -0.075], [-0.25, -0.075, 1]]`.
The Schur off-diagonal is `C_jk − C_ij·C_ik/C_ii`. In binary64, `fl(0.30)·fl(-0.25)` is exact
(division by 4 is an exact binary scaling) and equals `fl(-0.075)` bit for bit. Verified with
exact `fractions.Fraction` arithmetic: the difference is **exactly 0**.

The primary test file states this was deliberate (`test_m245_primary_core.py:211-213`):
*"C_jk=C_ij*C_ik/C_ii makes rho_c exactly zero … This exercises the complete outer Galerkin
path cheaply."*

Consequence inside the replica: `ell = 0`, `s = 1`, `eta = 0`, so `_conditional_means`
`:583-594` loses its dependence on the inner variable `h`, and the inner integrand
`:670-676` collapses to **`constant · φ(t)`**.

All SPD guards pass: `C00 = 1`, 2×2 minor `0.91`, `det = 0.853125`, `var_j = 0.91`,
`var_k = 0.9375`.

### 3.2 The gate is mpmath's own convergence test, and it is ABSOLUTE

`mpmath/calculus/quadrature.py:740` — `epsilon = ctx.eps/8`, computed at the ambient
precision *before* `ctx.prec += 20`.
`quadrature.py:239` — `if err <= epsilon: break`.
`m245_replica_core.py:538,562` — `saved_eps = mp.mpf(mp.eps)` at the same ambient precision,
then `quadrature_call_gate(error, saved_eps)` = `error <= saved_eps/8`.

These are the **same number**. Therefore `quadrature_call_gate` fails **if and only if**
`mp.quad` exhausted `maxdegree=14` without declaring convergence. Both thresholds are
absolute, not relative.

Precision ladder (measured):

| dps | ambient | inside outer quad | inner evaluation | inner gate `saved_eps/8` |
|---|---|---|---|---|
| 80 | 269 b | 289 b | 309 b (~93 digits) | `2.5135e-88` |
| 100 | 336 b | 356 b | 376 b (~113 digits) | `1.7032e-108` |

### 3.3 The outer panel list ends at infinity, and tanh-sinh goes there

`_outer_panel_bounds` `:761-767` gives `α = 0.1`, no collision with a base panel, so
**9 panels**, the last being `[16, inf)`.

mpmath's `transform_nodes` for `b == inf` (`quadrature.py:117-125`) uses `u = 2/(x+1)`, and
`calc_nodes` (`:369-374`) appends both `+x` and `−x` and only stops once `|x−1| ≤ 2^(-prec-10)`.
So the node nearest `x = −1` maps to an enormous `t`. Measured directly:

| | nodes at degree 1 | max node `g` |
|---|---|---|
| dps 80, prec 289 | 19 | **2.5179e+61** |
| dps 100, prec 356 | 21 | **1.7422e+101** |

This happens at **degree 1** — the very first evaluation of that panel.

### 3.4 The inner integrand magnitude grows linearly with the outer node

Independently re-derived (`independent_arithmetic_check.py`), magnitude of the inner
panel `[0, 0.25]` integral as a function of the outer node `g`:

| `g` | 16 | 1e3 | 1e6 | 1e10 | 1e20 |
|---|---|---|---|---|---|
| \|panel\| | 0.96 | 67.0 | 6.71e4 | 6.71e8 | 6.71e18 |

Slope ≈ `0.067·g`. At the degree-1 node `g = 2.5179e61` the panel value is **≈ 8.5e59**.

### 3.5 Measured: where the absolute gate becomes unsatisfiable

Generic probe at prec 289, `maxdegree=14`, integrand `constant · exp(-t²/2)` over `[0, 0.25]`


## 4. A retracted elimination (please read this one)

I first eliminated the whole "nested `mp.quad`" family on the grounds that cmd1's
`run_primary_event` nests `_integrate_half_normal` → `b_at` → `_primary_b_from_parameters`
→ sixteen `_gateway_request` calls, and cmd1 passed.

**That elimination does not hold.** For this event ρ_c = 0, and
`m245_primary_core.py:305-309`:

```python
def plackett_panel_bounds(rho_c):
    ...
    return tuple(rho * index / 16 for index in range(17))
```

With `rho = 0` this is **seventeen zeros**. All sixteen primary inner panels are degenerate
`[0, 0]`, and mpmath's `summation` does `if a == b: continue` (`quadrature.py:217-218`),
returning `(0, 0)` without evaluating anything. That trivially satisfies the gate.

**cmd1 never executed a single real nested quadrature on this event.** The replica's
`INNER_BASE_PANELS` are frozen and non-degenerate, so the replica runs 8 real inner tanh-sinh
quadratures per `b` evaluation regardless of ρ_c. cmd1 licenses nothing about the replica's
nested inner-quadrature behaviour.

### The architectural asymmetry this exposes

- **Primary** nested integrand: `_bivariate_pdf` (`:511-516`), a probability density bounded
  by `1/(2π√δ)`. Its panel integrals are O(1) at every outer node, so an absolute gate is
  always satisfiable.
- **Replica** nested integrand: `φ(t)·(centered_j·centered_k)` (`:670-676`). Its magnitude
  scales linearly with the *outer* node `g` whenever `C[i][j]` or `C[i][k]` is nonzero, and
  `_outer_panel_bounds` terminates with `mp.inf`.

The replica feeds unbounded-magnitude integrands into an absolute gate. The primary does not.

**Why cmd2's own passing tests did not catch it:** `_dummy_event(rho)` and
`_closed_form_dummy(rho)` both have `C[i][j] = C[i][k] = 0`, so `nu_j` and `nu_k` do not
depend on `g` at all — `b(g)` is constant and O(1) at every node, including 1e61. Lines 12
and 13 could not have hit this. Neither could the in-flight test at line 16, which also uses
`_closed_form_dummy` — so its silence is not evidence either way. `_varying_dummy_event` is
the only event in the replica suite that makes `b(g)` grow with `g`.

## 8. Decidability — plain statement

1. **The class of cause is decided.** An `Exception` was raised by the replica implementation
   inside `run_replica_event`'s outer integration, after hours of successful work.

2. **"Interruption-adjacent artifact" is eliminated outright** — not on numerics, but on the
   hard fact that `unittest` catches only `Exception`, and nine tests ran afterward.

3. **"Environmental" survives only as C3 (MemoryError), ranked third**, and even that would be
   exhaustion caused by the replica's own workload rather than an external event.

4. **A genuine, reproducible contract failure is the best-supported reading.** C1 is
   deterministic, is reached unconditionally once the finite outer panels complete, and is
   backed by measured evidence with ~10 orders of magnitude of margin. It also names a real
   defect: the replica applies an **absolute** quadrature error gate to a nested integrand
   whose magnitude is unbounded in the outer node, on a panel list that runs to infinity.

5. **What is NOT statically decidable: which single raise-site fired.** Five causes funnel
   into the same wrapped `M245ReplicaContractError` at `:557`, and no traceback exists. If the
   adjudication needs the exact site rather than the class, static analysis cannot supply it.

6. **One settling check exists that does not rerun cmd2**: evaluate `run_replica_event` on the
   varying dummy event outside the frozen test file, or read `b(g)` at the `[16, inf)` degree-1
   node directly. Either names the raise-site exactly. The sealed charter forbade this agent
   from doing it. Stated as an option, not a recommendation.
