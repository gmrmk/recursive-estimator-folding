# M199 result: composed cost remains blocked on overlap

Disposition: **`BLOCKED_OVERLAP`**.

M199 does not kill the exact-control architecture, and it does not certify that
the architecture fits. The existing artifacts cannot establish one legal
composed total.

The corrected standalone M125b carrier/background trace (`12.819202000B`) is

M179's standalone 31-layer archive is `8.304492288B`. With no replacement

```text

```

That leaves `1.986871472B` before the missing provider/compiler, M172, M198,
terminal `mu_32`, copies/allocations, and integrated residual wall. Because

The tempting replacement sensitivity is:

```text
89.708636240 - 7.736750160 + 8.304492288 = 90.276378368B.
```

It is not legal credit. The legacy background row is a protected 32-layer
trace, M179 is an unprotected 31-layer component that excludes terminal
`mu_32`, the numerical policies differ, and no trace identifies the exact
deleted call, operands, dtype, result, or lifetime. Applying a second 1.25
reserve to M179 gives other sensitivities, not evidence; it cannot fire the
frozen `KILL_COST` gate.

## Two independent audits

The static-workbook audit follows M148's common subtotal into M151 and proves
that M125b is already counted once. The executable-ABI audit confirms that
M179 emits M125-compatible Jacobians, but interface compatibility does not
prove billed call replacement. Both audits reject a second M125b charge and
reject free M179/background sharing.

The tangent and background matmuls are also genuinely different:

```text
M179:  a = mu W,       C = W^T V W
M125b: du = u W,      dC = W^T U W
```

Their operands and results differ for a nonzero tangent. Sharing the M179
Jacobian is plausible; sharing these matmuls is not.

## Required integrated trace interface

The only admissible repair is one streaming 31-layer pass:

```text
for layer ell:
    archive = m179_step(W_ell, mu_prev, V_prev)
    tangent = m125b_transport(tangent, W_ell, archive.J)  # ell > 1
    packet = layer_bound_source211(archive, W_ell)        # missing
    tangent += m198_delay_one(packet, archive)
    release layer-only buffers
terminal = explicit_mu32_and_response(...)
```

`ArchiveLayer` must expose the exact live buffers `W`, `a`, `C`, `mu`, `V`,
and `p,r,K,Hmu,Hv`. M125b must borrow the M179 Jacobian buffers; M198 must
consume the exact `a,C,mu` buffers; a source packet must bind its weight and
owner covariance by buffer identity to the same archive layer. Copies are
additive.

The trace report must record, for every operation: source location, dtype,
shapes, input/output buffer IDs and digests, birth/death sequence, billed
FLOPs, residual seconds, and one classification from `shared`,
`proved_replacement`, `additive`, or `unknown`.

Minimum counters include:

- M179: 31 row-square means, 62 square matmuls, and 1,011,840 exact pair/Jacobian assemblies;
- M125b: 30 mean transports, 60 covariance transports, and 31 ordered source injections;
- M151: 93 B=1 map/emission calls, 3,968 residual coefficient calls, and 155 five-product batches if actually invoked;
- M172/M198: 31 owner/source validations and 31 delay-one conversions;
- one explicit terminal readout.

The stream must retain only the weights, previous/current background, one
tangent accumulator, one Source211 packet, and M198 scratch. A 31-layer archive,
dense `distinct_211[256,256,256]`, or per-source suffix states is prohibited.
Actual peak memory must be at most 512 MiB.

## Current first breaks

1. M198's generated helper reruns M179; an integrated path must pass an already
   live archive entry instead.
2. `issue_m172_source` accepts caller-provided weight/covariance not bound to
   the archive. The source compiler must derive them from the same layer.
3. The exact covariance object owned by M163/M172 versus the pre-ReLU `C` used
   by M198 is not frozen in an integrated ABI.
4. The target-width Source211 provider/compiler is absent.
5. M198's scalar/special-function work has no native cost.
6. M151's call counts are worksheets, not a composed executable trace.
7. M179 excludes terminal `mu_32`; no full legacy-background replacement is
   possible without a charged terminal path.

## Reopening condition

The only lawful M200 child is a response-free streaming overlap harness with
an opaque, explicitly unpriced Source211 fixture. It may prove buffer reuse,
calls, liveness, and downstream cost. It cannot claim estimator cost or
efficacy until the real provider replaces the fixture.

Machine-readable evidence and arithmetic guards are in
`m199_cost_ledger.json`, `m199_cost_reconciliation.py`, and
