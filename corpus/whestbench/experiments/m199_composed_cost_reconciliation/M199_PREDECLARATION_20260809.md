## One changed mechanism

Replace the invalid arithmetic

```text
M151 remainder = free provider budget
```

with one call/operation DAG covering:

- the frozen M151 known endpoint work and its protected common subtotal;
- the exact M179 zero-order/Jacobian archive;
- the existing M125b background/carrier work already present in M151;
- M172 owner transfer and M198 delay-one conversion;
- every unimplemented source-state/provider/compiler operation as an explicit
  unknown rather than zero.

Every operation family must be classified as exactly one of:

1. **identical shared call** -- same operands, shape, dtype, result, lifetime,
   and billed call; counted once;
2. **proved replacement** -- the child removes a named parent call and emits an
   arithmetic-identical result; child cost replaces parent cost;
3. **additive** -- different operands/result/lifetime or no exact reuse proof;
4. **unknown/untraced** -- retained as a nonnegative symbolic variable and
   never credited as zero.

No algebraic similarity, shared formula, or common node name creates sharing.
